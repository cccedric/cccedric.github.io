### 下载 Miniconda 安装脚本

创建一个目录用来存放安装文件，然后使用 wget 下载最新的 64 位 Linux 安装包：
````markdown
mkdir -p ~/miniconda3
wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh -O ~/miniconda3/miniconda.sh
````

### 运行静默安装

自动将 Miniconda 安装到 ~/miniconda3 目录下（-b 表示静默模式，不需要一路按 Enter 和 yes）：
````markdown
bash ~/miniconda3/miniconda.sh -b -u -p ~/miniconda3
````

### 初始化 Conda

将 Conda 的环境变量写入你的终端配置文件中。如果你使用的是默认的 bash：
````markdown
~/miniconda3/bin/conda init bash
````

### 初始化 Conda

刷新你的环境变量，使 Conda 立即生效，并删除刚才下载的安装包以节省空间：
````markdown
source ~/.bashrc
rm ~/miniconda3/miniconda.sh
````

### 验证安装

如果终端打印出了 Conda 的版本号（例如 conda 24.1.2），说明安装完美成功
````markdown
conda --version
````

### 配置清华高速镜像源
````markdown
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/main/
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/free/
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud/conda-forge/
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud/pytorch/
conda config --set show_channel_urls yes
````
